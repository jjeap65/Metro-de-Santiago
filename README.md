# Ascensores Metro Santiago - PWA

Progressive Web App para consultar información técnica de todos los ascensores del Metro de Santiago.

## 🎯 Características

- ✅ **415 ascensores** de todas las líneas del Metro
- ✅ **100% offline** - funciona sin conexión una vez instalado
- ✅ **Instalable en iPhone** - agregar a pantalla de inicio
- ✅ **Interfaz intuitiva** - selección por Línea → Estación → Ascensor
- ✅ **Colores por línea** - cada línea usa su color oficial
- ✅ **Información completa** - Marca, Modelo, Año, Tecnología, Contrato, Código

## 📱 Uso

1. Abre la app: https://[tu-usuario].github.io/metro-ascensores/
2. Selecciona una **Línea** (L1 - L6)
3. Selecciona una **Estación**
4. Selecciona un **Ascensor**
5. ¡Listo! Verás todos los detalles técnicos

### Instalación en iPhone

1. Abre en Safari
2. Toca el botón "Compartir" (cuadrado con flecha hacia arriba)
3. Selecciona **"Agregar a Inicio"**
4. Ahora funciona como una app nativa y offline

## 🛠️ Tecnología

- HTML5 + CSS3 + JavaScript vanilla (sin frameworks)
- Service Worker para caché offline
- PWA Manifest para instalación
- Datos embebidos (no requiere backend)

## 📊 Datos

Base de datos: `Consolidado_Ascensores_Metro_Línea.csv`  
Total: 415 ascensores en 132 estaciones
